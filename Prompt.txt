You are a senior full-stack engineer and product designer.

Build a working MVP for my startup:

PRODUCT NAME:
AI Email Action Manager

TAGLINE:
"From Inbox Overload to Clarity & Action"

CORE IDEA:
People receive dozens or hundreds of emails every day. Important emails, promotions, newsletters, bills, notifications, and work emails get mixed together.

Our product connects to Gmail, uses AI to understand emails, identifies which emails actually require attention, extracts actions and deadlines, and converts the inbox into a prioritized daily action list.

IMPORTANT:
This is an MVP for a student startup project with a ₹20,000 budget.

Do NOT over-engineer it.
Do NOT build a Chrome extension.
Do NOT build a mobile app.
Do NOT build unnecessary enterprise features.

Build a polished web application first.

6. AI EMAIL ANALYSIS
--------------------------------------------------

This is the core feature.

For every email, ask the AI to determine:

1. Category
2. Priority
3. Whether action is required
4. Required action
5. Deadline
6. Short summary
7. Reason for priority

Categories:

- Action Required
- Work
- Personal
- Transaction
- Promotion
- Newsletter
- Social
- Notification
- Spam
- Other

Priority:

- HIGH
- MEDIUM
- LOW
- NONE

Action Required:

true / false

Deadline:

Extract a specific date when possible.

If no deadline exists:

null

Action:

Example:
"Reply to client"
"Pay electricity bill"
"Submit assignment"
"Confirm meeting"

If no action is required:

null

Summary:

Maximum 2 sentences.

Reason:

Short explanation of why the email received its priority.

--------------------------------------------------
7. USE STRUCTURED AI OUTPUT
--------------------------------------------------

The AI MUST return structured JSON.

Example:

{
  "category": "Action Required",
  "priority": "HIGH",
  "action_required": true,
  "action": "Confirm revised project deadline",
  "deadline": "2026-08-25",
  "summary": "Client requested confirmation of a revised project deadline.",
  "reason": "The email requires a response and has a specific deadline."
}

Do not depend on free-form AI responses.

Validate the JSON before saving it.

If AI returns invalid JSON:
- retry once
- otherwise mark the email as "Needs Review"

--------------------------------------------------
17. SECURITY
--------------------------------------------------

Implement basic security best practices.

- Never expose API keys in frontend code.
- Store secrets in environment variables.
- Validate OAuth tokens.
- Validate all user inputs.
- Use secure session handling.
- Prevent unauthorized access between users.
- Never allow User A to access User B's emails.
- Do not log complete email contents.
- Do not expose API keys.
- Use HTTPS in deployment.
- Add basic rate limiting where practical.
